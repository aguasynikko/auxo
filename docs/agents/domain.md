# Domain docs

- Glossary (ubiquitous language): `docs/GLOSSARY.md`
- Architecture decisions: `docs/adr/NNNN-<slug>.md` (one decision per file, numbered, never edited after acceptance — supersede instead)
- Spec: `docs/SPEC.md`

Agents read the glossary before naming things and add an ADR when a decision is made or changed.
