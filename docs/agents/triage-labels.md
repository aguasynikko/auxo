# Triage labels

| Label | Meaning |
|---|---|
| `needs-triage` | New, not yet reviewed |
| `needs-info` | Blocked on a question for a human |
| `ready-for-agent` | Fully specified; an agent can pick it up |
| `ready-for-human` | Needs human judgment or access (credentials, design call) |
| `wontfix` | Closed without action (GitHub default label) |

Also uses GitHub defaults: `bug`, `enhancement`, `documentation`.
Custom labels are created on GitHub when the first tickets are published.
